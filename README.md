1. Executive Summary & Purpose
Movie Explorer is a modern, responsive single-page web application built with React and Vite, powered by the real-time public TVMaze API. It was built to satisfy all assignment requirements with additional production-grade features such as:

Instant debounced search
Genre filtering and multi-attribute sorting
An interactive details modal
An integrated HD video trailer player
Responsive glassmorphic UI design
